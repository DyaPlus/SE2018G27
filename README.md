<h1>Hospital Management System (HMS)</h1> 
<p>it is web based software system made for hospitals in order to ease the medical process and provide a predefined steps for the patients and employees. It should provide various subsystems for different medical aspects like imaging and examinations and most importantly keeping the patient updated with online profile system , achieving that with security in mind for information safety and healthy system.It
allows the partnership of pharmacies with ease .</p>
